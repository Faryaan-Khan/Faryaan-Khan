### Projects

- **[Anime Auction Draft](https://github.com/Faryaan-Khan/anime-encheres)**: a two-player bluffing
  auction game in the browser. Play on one phone, against a computer opponent that plays out the
  rest of the game before each bid, or online in real-time rooms where the hidden card never
  leaves the server. 326 characters, French and English.
  *TypeScript, Supabase (Postgres, Realtime, Edge Functions)*

- **[Resume / Job Matcher](https://github.com/Faryaan-Khan/resume-matcher)**: upload a resume and a
  job description, get a match score that breaks down into skill coverage, semantic similarity and
  keyword overlap, plus LLM-written suggestions and a cover-letter draft.
  [Live demo](https://resume-matcher-g7ezuzpx3s5zr7kcvfvrrc.streamlit.app).
  *Python, OpenAI embeddings, Streamlit*

- **[Nasi Lemak Index](https://github.com/Faryaan-Khan/nasi-lemak-index)**: where is Malaysia's
  grocery basket cheapest, and what spikes before Raya and CNY? 47M+ government price records
  (DOSM PriceCatcher) in a pipeline that refreshes itself daily.
  *DuckDB SQL, Python, GitHub Actions, Power BI*

- **[MazeNavigator](https://github.com/Faryaan-Khan/MazeNavigator-)**: a maze-chase game where four
  ghost agents each follow their own targeting rule to hunt the player.
  *Python, Pygame*
